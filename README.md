Hungry Frog 🐸

Hungry Frog is a simple, interactive browser fun game built using HTML, CSS, and JavaScript. Players control a hungry frog from aiming to catch as many flies as possible while avoiding obstacles. This project was developed as a collaborative team game.

FEATURES
Fast paced,responsive game play mechanics
Dynamic obstacles generation to increase difficulty over time
High score tracking to challeng players
Clean and intuitive user interface

Installation
Clone the repository:
git clone http://github.com/your-username/hungry-frog.git
Navigate to the project directory: cd hungry-frog
Install the required dependencies npm install
Start the application npm start

How to play
Action: Press the mouse to extend the tongue and catch the mouse
Goal: Eat as many flies as you can before the timer runs out 

Tech Stack
Frontend, HTML,CSS and Javascript
Build Tools: Prettier
